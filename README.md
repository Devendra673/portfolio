# Devendra — Portfolio

Personal portfolio site. Single-page, dark-first, with a WebGL particle background.

**Live:** _add URL after deploying_

## Stack

- **Framework:** Next.js 16 (App Router) · React 19 · TypeScript
- **Styling:** Tailwind CSS v4 (CSS-native `@theme`, no config file)
- **Motion:** Framer Motion
- **3D:** Three.js via React Three Fiber (custom GLSL particle shader)
- **Icons:** Lucide React

## Local development

```bash
npm install
npm run dev      # http://localhost:3000
npm run build    # production build
npm run lint     # eslint
```

## Structure

```
app/
├── layout.tsx              # metadata, fonts, theme script, JSON-LD
├── page.tsx                # composes all sections
├── globals.css             # theme tokens, utilities, reduced-motion
├── opengraph-image.tsx     # generated social share card
├── sitemap.ts / robots.ts  # SEO
├── components/             # section + UI components
└── components/webgl/       # particle field (lazy-loaded, tier-gated)
lib/
├── data.ts                 # all site content lives here
└── utils.ts                # cn() helper
public/
├── resume.pdf              # generated by generate_resume_pdf.py
└── projects/               # project screenshots
```

## Editing content

All copy, projects, experience, education and skills live in `lib/data.ts`.
No text is hardcoded in components.

## Resume

`public/resume.pdf` is generated from a script so it stays reproducible:

```bash
pip install reportlab
python generate_resume_pdf.py
```

Single page, ATS-friendly (single column, no tables, Helvetica, ASCII only).

## Environment variables

| Variable | Purpose |
| --- | --- |
| `NEXT_PUBLIC_SITE_URL` | Canonical site URL used by metadata, sitemap and robots. Set this in Vercel. |

## Accessibility notes

- Content renders fully without WebGL; the canvas is decorative and `aria-hidden`
- Particle field respects `prefers-reduced-motion` and degrades on low-core devices
- Hover-revealed screenshots stay visible on touch devices via `@media (hover: none)`
- Skip-to-content link, visible focus rings, semantic landmarks
